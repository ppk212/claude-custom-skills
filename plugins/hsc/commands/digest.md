# Digest — 주제별 종합 문서

`$ARGUMENTS`가 주제(검색어)다. 비어 있으면 무엇을 정리할지 묻고 멈춘다.

## 1. 관련 대화 검색

```bash
node "${CLAUDE_PLUGIN_ROOT}/digest/search-sessions.js" --query "$ARGUMENTS"
```

- `관련 대화를 찾지 못했습니다`면 다른 검색어(영문/한글, 더 짧은 단어)를 제안하고 끝낸다.
- 출력 끝의 `search:` 경로를 Read로 읽고, `doc:` 경로를 기억한다.
- 관련도 높은 60개만 담긴다. 일부가 제외됐다고 나오고 내용이 부족해 보이면 `--limit 150`으로 다시 검색한다.
- 비밀값은 스크립트가 이미 가렸다.

## 2. 종합 문서 작성

`doc:` 경로에 Write로 쓴다.

```json
{
  "name": "주제명 (명확하고 구체적으로)",
  "tags": ["프로젝트폴더명", "기술태그"],
  "details": "마크다운 종합 문서"
}
```

**details 구성** (해당 내용이 없는 섹션은 뺀다)
- `## 개요` 이 주제가 무엇이고 지금 어떤 상태인지 한 문단
- `## 타임라인` 날짜별로 무슨 일이 있었는지 시간순
- `## 상세 내용` 핵심 결정과 그 이유, 알아낸 사실
- `## 코드·명령·설정` 코드 블록(```언어)으로 구체적인 값
- `## 관련 파일` 언급된 경로
- `## 미해결` 남은 일

여러 세션의 내용은 시간순으로 합치고 중복을 없앤다. 각 사실 뒤에 출처 날짜를 `(10/14)`처럼 붙인다. "분석했다"로 끝내지 말고 무엇을 알아냈는지 쓴다.

같은 `name`의 문서가 이미 있으면 그 뒤에 날짜 구분과 함께 덧붙여진다. 앞서 정리한 주제를 이어 쓰는 거라면 같은 이름을 쓴다.

## 3. Notion에 기록

```bash
node "${CLAUDE_PLUGIN_ROOT}/digest/digest-to-notion.js"
```

`설정이 없습니다`로 끝나면 `/hsc:setting`을 안내한다. 성공하면 작업 파일은 지워지고 Notion 링크가 출력된다. 문서 제목, 포함한 기간과 세션 수, 링크를 보고한다.
