# 요구사항 md 템플릿

이 파일을 복사해 채운 뒤 URL과 함께 넘기면 된다.

```
/hsc:design-sample-lab https://stg.example.com/page ./내-요구사항.md
```

**형식은 자유다.** 스킬이 읽고 `R1 · R2 · R3 …` 체크리스트로 정규화한다.
정해진 머리말이나 순서를 지킬 필요는 없고, 아래 항목이 내용에 있으면 된다.

---

## 필수 3가지

### 1. 목표 — 한 줄

무엇을 하려는지. `현재 서비스 중인 사이트의 디자인을 변경한다` 정도면 충분하다.

### 2. 현재 상황 — 이 페이지가 뭐 하는 곳인지

스킬이 화면을 읽어 구조는 파악하지만, **화면에 안 적힌 사업 맥락은 모른다.**
어떤 서비스이고 사용자가 여기서 무엇을 하는지 2~3줄로 적어라.

### 3. 문제점 / 해결하고 싶은 점 — 가장 중요

**증상을 적고 해법은 적지 마라.** "히어로를 크게 키워달라"가 아니라
"이 화면에서 할인 폭이 눈에 안 띈다"라고 적는다. 해법을 지정하면 11개 시안이
전부 같은 답을 낸다 — 여러 방향을 보려고 이 스킬을 쓰는 의미가 사라진다.

사용자가 화면 앞에서 던질 법한 질문 그대로 쓰는 게 가장 잘 통한다.

---

## 적으면 결과가 확 좋아지는 것

### 제약 — 바꾸면 안 되는 것

**이게 빠지면 시안 전체가 폐기될 수 있다.** 브랜드 컬러, 유지해야 할 명칭,
없애면 안 되는 기능 블록, 법적 고지 등.

### 숫자와 사실

시안에 박히는 값이다. **화면에 보이는 값과 실제 정책이 다르면 반드시 적어라.**
이걸 안 적으면 스킬이 되물어야 하고, 안 물으면 22개 파일에 틀린 숫자가 박힌다.

### 대상 화면

안 적으면 URL이 가리키는 그 페이지 하나만 대상으로 한다.

### 타깃 사용자 / 주 유입 경로

모바일 우선인지 데스크톱 우선인지가 갈린다.

---

## 적지 않아도 되는 것

- **디자인 방향** (미니멀·브루탈리즘 등) — 스킬마다 각자 정한다. 여기서 못 박으면 시안이 다 비슷해진다
- 폰트·컬러 구체값 — 제약에 해당하는 것만 적으면 된다
- 현재 화면 구조 설명 — 스킬이 직접 읽는다

---

# 작성 예시

아래는 실제로 돌려서 시안 11종이 나온 입력이다. 이 정도 분량이면 충분하다.

```markdown
목표 : 현재 서비스 중인 사이트의 디자인을 변경한다.

현재 상황
- 사이트는 https://stg.charancha.com/weekly-car 이다.
- 해당 사이트에서는 차량의 가격을 1000만원 할인해주는 이벤트를 진행하며
  응모 후 추첨을 통해 할인된 차량을 살 수 있는 권리를 부여한다.

문제점 및 해결하고 싶은 점
- 사이트에서 다음 항목이 눈에 띄지 않으며, 이런 항목들이 눈에 띄게 되어야 한다.
	- "이 차가 그래서 얼마나 저렴한데?"
	- "그래서 위클리카가 뭔데?"
	- "응모 추첨으로 당첨되면 내가 돈을 얼마 버는건데?"
- 사이트의 퀄리티가 낮아보이는 원인을 아래 내용으로 추측하고 있으며 이를 해결해야한다.
	- 글자 폰트의 사이즈를 너무 다양하게 사용하고 있다.
	- 각 div 간의 위아래 간격이 일정하지 않다.
```

## 이 예시가 잘 통한 이유

- **문제를 사용자 질문으로 적었다.** "이 차가 그래서 얼마나 저렴한데?" 같은 문장은
  시안마다 다르게 답할 여지를 남긴다. 실제로 11종이 전부 다른 방식으로 답했다.
- **원인 추측을 적었다.** "폰트 사이즈가 다양하다", "간격이 일정하지 않다"는
  측정 가능한 항목이라 그대로 판정 기준이 됐다.

## 이 예시에 없어서 아쉬웠던 것

- **제약이 없었다.** 브랜드 블루를 유지해야 하는지, 미션·응모권 섹션을 없애도 되는지
  적혀 있지 않아 스킬이 현재 화면에서 추론해 채웠다.
- **숫자가 화면과 달랐다.** md는 `1000만원 할인`인데 실제 화면은 `-500만원`이었다.
  어느 쪽을 쓸지 되물어야 했다. 아래처럼 적었으면 안 물어도 됐다.

```markdown
제약 (바꾸면 안 되는 것)
- 브랜드 블루 #0740E4 계열을 주 색상으로 유지
- "차란차", "위클리카", "응모권" 명칭 유지
- 카운트다운 / 차량 정보 / 응모권 / 미션 / 공개예정 / 유의사항 / 사업자정보 블록 유지

숫자 기준
- 정상가 3,000만원 → 특가 2,000만원 (지원금 -1,000만원, 할인율 33%)
- STG 화면에는 1회차 테스트 데이터로 -500만원이 떠 있으나, 위 값을 쓸 것

타깃
- 20~40대, 앱 웹뷰 유입이 주력이므로 모바일에서 성립하지 않으면 실패
```
